# Conversor de Moeda

Conversor de moedas feito em JavaScript puro, como projeto de estudo de front-end.

## Funcionalidades

- Conversão entre Real, Dólar, Euro, Libra e Bitcoin
- Troca de bandeira e nome da moeda conforme a seleção
- Resultado formatado no padrão de cada moeda

## Tecnologias

- HTML, CSS e JavaScript (manipulação do DOM e `Intl.NumberFormat`)

## Próximos passos

- Buscar as cotações em tempo real por meio de uma API
